# MASTER PROMPT — LongYinLiZhiZhuan Co-op Mod

## เป้าหมาย
ทำ co-op mod ให้เกม LongYinLiZhiZhuan (Unity 2020.3.48f1c1 IL2CPP, MelonLoader 0.7.3 ที่ติดตั้งอยู่แล้ว)
ให้เพื่อนเข้าปาร์ตี้ ตาม host บนแผนที่ และคุมยูนิตในศึกเทิร์นเบสของ host ได้
โมเดลคือ host เป็นผู้ตัดสินเพียงคนเดียว (authoritative) guest ไม่จำลอง ไม่สุ่ม ไม่คำนวณผล
เป็น co-op กับเพื่อนเท่านั้น ห้ามทำอะไรที่โกงในเกมออนไลน์ของคนอื่นหรือแตะระบบ anti-cheat

## เอกสารอ้างอิง (ถือเป็นแหล่งความจริงตามลำดับ)
STAGEPLAN.md > battle-notes.md, worldmap-notes.md > dump.cs
ถ้าเอกสารขัดกันหรือขัดกับสิ่งที่วัดได้จริง ให้หยุดแล้วรายงาน อย่าเลือกเอง

## กติกาตายตัว
1. ทำทีละ stage ตาม STAGEPLAN เท่านั้น ห้ามข้าม ห้ามทำล่วงหน้า ห้ามขยายขอบเขต
   ก่อนเริ่มแต่ละ stage รายงานแผนของ stage นั้นแล้วรอฉันอนุมัติ
2. จบแต่ละ stage ต้องมีรายงานผลวัดเทียบ exit criteria ทีละข้อ, hash เซฟก่อน/หลัง, git tag stage-SN
   ถ้าข้อไหนไม่ผ่าน ให้บอกตรง ๆ ว่าไม่ผ่าน ห้ามเลื่อนเกณฑ์เอง
3. ใช้ตารางสิทธิ์การเขียนใน STAGEPLAN §1.1 เป็นข้อบังคับ stage ไหนห้ามเขียนก็ห้าม
4. ทดสอบบนสำเนาเซฟเท่านั้น ตามโปรโตคอล §1.2 ห้ามแตะเซฟจริง
5. ห้ามแตะ Steam, achievements/stats, APIDispatcher, DnsChecker, CheatCheck และ flag cheat* ในเซฟ
6. ทุกการเรียก IL2CPP ต้องผ่านคิวและรันบน Unity main thread ตาม §1.4
7. ต้องมี rollback ที่ใช้ได้จริงทุก stage (pref, .dll.off, git tag)
## กติกาเพิ่มเติม
8. ในโค้ด mod ให้เข้าถึงข้อมูลผ่าน Il2CppInterop แบบมีชนิด (เช่น heroData.bigMapPos, text.text)
   ห้ามอ่าน/เขียนด้วย raw offset หรือ pointer ยกเว้นไม่มีทางอื่น และต้องบอกฉันก่อน
   offset ใน notes มีไว้สำรวจเท่านั้น
9. ปักหมุดเวอร์ชันเกม: บันทึก SHA-256 ของ GameAssembly.dll และ global-metadata.dat ไว้ใน VERSION.md
   ตอนเริ่มทุก session ให้เทียบ hash ถ้าเกมอัปเดต ให้หยุดและรายงาน ห้ามเดาว่ายังใช้ได้
10. โปรเจค mod อยู่นอกโฟลเดอร์เกม (git repo แยก) build แล้วค่อย copy DLL เข้า Mods\
    ห้าม commit DLL ของเกม, Il2CppAssemblies หรือ dump.cs เข้า git

## วินัยเรื่องหลักฐาน
- ทุกข้อเท็จจริงติดป้าย RUNTIME / DUMP / GUESS / SPEC
- ห้ามเขียนว่าอะไรยืนยันแล้ว ถ้าไม่ได้วัดหรือเห็นเอง
- ค่าที่ถอดจาก hex หรือ memory read ให้ตรวจซ้ำกับตัวเลขบนจอก่อนใช้
- RVA/offset จาก notes ยังไม่ถือว่ายืนยัน ต้อง re-resolve ผ่าน interop ก่อนใช้เขียน
- เจอสิ่งที่ขัดกับที่เคยเขียนไว้ ให้แก้เอกสารและบอกฉัน อย่าเงียบ

## เมื่อไรต้องหยุดถามฉัน
- เกม crash, เทิร์นค้าง (soft-lock), หรือเซฟ hash เปลี่ยน
- ต้องทำสิ่งที่นอกตารางสิทธิ์ หรือนอกขอบเขต stage
- มีหลายทางเลือกที่ต่างกันที่ความเสี่ยงต่อเซฟหรือ Steam
- ผลวัดต่างจากสมมติฐานของแผนอย่างมีนัยสำคัญ

## ห้ามทำ
- ห้ามสำรวจนอกเรื่อง (IAP, เพิ่ม stat, โกง) แม้จะมีปุ่ม followup แนะนำ
- ห้ามเพิ่ม dependency ใหม่หรืออัปเกรด/ดาวน์เกรด MelonLoader โดยไม่ถาม
- ห้ามแก้ไฟล์ของ mod อื่น (LongYinThai, UnityExplorer)

## ภาคผนวก A — เกณฑ์ตัดสินฉบับที่ 2 [CRITERIA] (มติผู้ใช้ 2026-10-29 หลัง pilot A1-r1 — ล็อกก่อนรัน A3-r1)

> **สถานะของ A1-r1:** MISMATCH ตาม [TOL]=0.1 เดิมคงอยู่ตามจริง (`analyze-result.txt` ไม่แก้) — จัดเป็น
> **pilot — ไม่นับเป็นผลยืนยัน** (`evidence\V2A-a1r1-20261029-022648\pilot-a1r1-analysis.md`) · ตั้งแต่รัน A3-r1
> เป็นต้นไปตัดสินด้วยเกณฑ์นี้เท่านั้น — ผล `time_v2a_analyze.py --tolerance 0.1` รายรอบคงพิมพ์ตามจริงเป็น
> ข้อมูลประกอบ แต่**ไม่ใช่ตัวตัดสินผ่าน/ไม่ผ่านอีกต่อไป**

- **โครง:** ทุกรัน `day_ticks == N` **และ** ลำดับ event ตรงโครง = `work_start → pause_end → [day_tick →
  pause_end]×N → work_end` (ตาม static §2.4; abort = work_abort แทน work_end)
- **ความชัน:** fit เชิงเส้น `measured = slope×N + intercept` จาก **N=1,5,10 ทุกรอบรวม** (least squares ราย run —
  เฉพาะรอบ normal A1/A2/A3; **รอบ skip A4 รายงานแยก ไม่เข้า fit** เพราะ k ต่าง) —
  slope ต้องอยู่ใน **1.25 ± 0.1 s/วัน** ผิด = **MISMATCH จริง → หยุดรายงาน**
- **ฟอร์ม (ตัวเลขคงเดิมทุกตัว — มติรอบ A):** จุด intercept อยู่ใน **[−0.1, +0.1]** = **FORM1** · ใน
  **[+0.4, +0.6]** = **FORM2** · จุด**นอกทั้งสอง window และไม่ใช่กรณีคาบเกี่ยว** = **UNRESOLVED_OFFSET**
  (รายงานค่า intercept + ช่วงความเชื่อมั่นถ้ามี — เชิงประมาณ ±1.96×SE ของ intercept จาก residual ของ fit เดิม)
  · **INDISTINGUISHABLE สงวนไว้เฉพาะกรณีคาบเกี่ยว/ข้อมูลไม่พอแยก** (ช่วงความเชื่อมั่นครอบ/ทับ**ทั้งสอง**
  window) — ทั้ง UNRESOLVED_OFFSET และ INDISTINGUISHABLE เป็น**ผลที่ยอมรับได้ ไม่ใช่ความล้มเหลว** ·
  **ห้าม refit โมเดล ห้ามเพิ่มพารามิเตอร์แอนิเมชันเข้าสูตรเอง**
- **ส่วนเกินที่อธิบายไม่ได้:** residual รายรัน = `measured − (slope×N + intercept)` รายงานเป็นค่าแยก — **ไม่ใช้
