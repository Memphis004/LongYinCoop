**สรุป:** คำขอ "ใช้ได้โดย `AllowRemoteInput=false` **และ `DevCommands=false`**" — ครึ่งแรกจริง (read-only ไม่แตะ `AllowRemoteInput`) แต่ครึ่งหลัง **ไม่จริง**: `DevCommands=false` ⇒ `spike status` ตอบ `dev commands disabled` ทันที

**ทางเลือก (ยังไม่เลือกเอง)**

- **(ก)** ยอมให้ `DevCommands=true` + `AllowRemoteInput=false` แล้วผ่อน guard ของ S2 ให้เช็คแค่ `AllowRemoteInput` (แก้ 1 บรรทัดใน `S2HostService`) — write path ยังปิดเพราะ `arm/move/attack` ต้อง `AllowRemoteInput` · `DevCommands` เป็น default เดิมของ mod อยู่แล้ว
