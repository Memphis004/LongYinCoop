## 4. Frida probes: บั๊กที่เจอและแก้

- `Il2Cpp.gc.choose(Text)` + เทียบ `transform.handle` **ไม่ตรงกัน** แม้เป็น object เดียวกัน → ต้องเทียบด้วย **ชื่อ** (`Text` / `Content` / `Viewport`)
- generic `GetComponentsInChildren<T>` เรียกผ่าน bridge ไม่ได้ (`expected an integer`)
- null ref ของ IL2CPP เป็น wrapper ที่ truthy → ต้องเช็ค `handle !== "0x0"` และครอบ try/catch ต่อยูนิต
- `ui-probe.js` คืน schema ที่ `compare_ui_frame.py` ใช้อยู่แล้ว (`frame`, `units[{heroID,teamIndex,hp,row,col}]`, `activeHeroID`, `activeCell`) — สิ่งที่ต้องแก้คือ **ตัว compare script** (join แบบ exact frame → nearest ±2 เพราะ sampler เขียนทุก ~3 เฟรม)
