## ข้อสรุปต่อคำถามเดิม

- **เวลาเดินแน่นอนเมื่อปาร์ตี้กำลังเคลื่อนที่** และ **HUD กับ IPC ตรงกันทุก sample** → ไม่ใช่บั๊กของ `WorldSampler`
- ค่าที่เคยเห็น "นิ่ง" (5.2903786 / 5.866481 / 22.04 ค้าง) เกิดขึ้นตอนปาร์ตี้ **อยู่นิ่ง** และบางช่วง **เกมไม่มีโฟกัส** (`isFocused=false` ตอนคุยกัน) → ตัวแปรนี้ต้องคุมให้ได้ก่อนสรุปเรื่อง accrual
- ยังไม่รู้ว่าก้อนเวลาเกิดจาก: เดินทีละก้าว / ข้าม area / ใช้ยานพาหนะเร็ว / กิจกรรมอื่น — ต้องทดสอบแยกทีละ action (เดินสั้นในที่เดิม, เดินข้ามเมือง, พักโรงแรม, เข้าศึก)
